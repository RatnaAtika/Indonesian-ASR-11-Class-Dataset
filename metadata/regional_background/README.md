# Reported Regional Background by Public Speaker Label

## Purpose and scope

This file documents the **reported place of origin/regional background** associated with the 20 retained human public speaker labels in NSS-ID. It was prepared from an author-supplied mapping on 25 August 2026.

Only the existing public pseudonymous labels (`F1`–`F8` and `M1`–`M12`) are reproduced here. Direct identifiers, respondent names, and the private identity crosswalk are not included.

> **Interpretation boundary:** these values are recruitment/background descriptors, not independently verified dialect labels and not recording-level dialect annotations. They must not be used to claim dialect classification, ethnicity, population representativeness, or dialect-specific model performance. Voice recordings remain potentially identifying even when public labels are pseudonymous.

## Recommended manuscript wording

> The release contains 20 retained pseudonymous human public speaker labels associated with 15 author-reported regional backgrounds. These values describe recruitment background only; no independently verified recording-level dialect labels are provided. The sample is not intended to represent the demographic, geographic, or dialect distribution of the Indonesian population.

## Responsible use and citation

Use this mapping only for bounded descriptive reporting. Do not use it to infer a speaker's ethnicity, verify dialect identity, perform geographic profiling, or claim regional/dialect fairness. When citing the mapping, cite the exact GitHub commit or Hugging Face dataset revision containing this file.
