 6 Journal Style Preset Built-in

 ```bash
   $ python3 training/common/journal_plotting.py --list-styles
     ieee        IEEE (1-col, sans-serif, BW-friendly)         figsize=(3.487, 2.6)
     acm         ACM (1-col, serif, color-friendly)            figsize=(3.33, 2.5)
     springer    Springer LNCS (single-col, serif)             figsize=(4.6, 3.0)
     elsevier    Elsevier (1-col, sans-serif, color OK)        figsize=(3.5, 2.7)
     thesis      Thesis / dissertation (full-page)             figsize=(6.5, 4.0)
     plain       Plain default                                 figsize=(8.0, 5.0)
 ```

 Setiap style menentukan: figsize (sesuai column-width jurnal), font family + size, line styles (dashed untuk
 BW print), grid policy, default DPI (600 untuk paper, 300 untuk thesis).

 4 Cara Replot

 ### 1. Per-model satu style

 ```bash
   python3 training/common/journal_plotting.py \
     --run-dir training/m02_whisper_small/runs/run_full_20260601 \
     --style ieee --formats png pdf svg
 ```

 Output: runs/run_full_20260601/plots_ieee/ dengan 7 plot × 3 format = 21 file (loss, acc, wer_cer, lr,
 gpu_mb, throughput, combined_4panel untuk paper Figure 1).

 ### 2. Semua 14 model satu style

 ```bash
   python3 replot_all.py --style ieee --pattern "run_full*" \
     --out-root reports/paper_figures_ieee
 ```

 Output 1 folder reports/paper_figures_ieee/ berisi 14 sub-folder model.

 ### 3. Multi-model overlay (paper Figure 2)

 ```bash
   python3 replot_compare.py \
     --runs training/m02_whisper_small/runs/run_full_*  \
            training_conventional/m12_vit_modified/runs/run_full_* \
     --labels "Whisper-small ★" "ViT-modified-ID ★" \
     --metrics wer cer train_loss val_loss \
     --style ieee --formats png pdf \
     --out reports/paper_figures_ieee/figure2_overlay.png
 ```

 Output: 1 figure 4-panel berisi 4 metric × N model overlay.

 ### 4. Semua 6 style sekaligus

 ```bash
   for STYLE in ieee acm springer elsevier thesis plain; do
     python3 replot_all.py --style $STYLE --pattern "run_full*" \
       --out-root reports/paper_figures_$STYLE
   done
 ```

 Hasil: 6 folder × 14 model × 7 plot × 2 format ≈ 1,176 file paper-ready, 25 menit total.

 Workflow Lengkap untuk Paper

 ```bash
   # 0. Training di terminal terpisah (RUN_GUIDE.md) → menghasilkan history.json per model
   # 1. Aggregate ke Tabel 1
   python3 aggregate_all_models.py
   # 2. Per-model figure dalam style jurnal target
   python3 replot_all.py --style ieee --pattern "run_full*" \
     --out-root reports/paper_figures_ieee --formats pdf png
   # 3. Multi-model overlay Figure 2
   python3 replot_compare.py --auto-discover --metrics wer cer \
     --style ieee --formats pdf \
     --out reports/paper_figures_ieee/figure2_overlay.pdf
   # 4. (opsional) Style alternatif untuk preferensi co-author
   for S in acm springer thesis; do
     python3 replot_all.py --style $S --pattern "run_full*" \
       --out-root reports/paper_figures_$S --formats pdf
   done
 ```
