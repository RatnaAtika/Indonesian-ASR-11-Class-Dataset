# Funding Statement

> Required by Elsevier for every submission. Choose one of the two
> templates below.

## Template 1 — Specific funding received

Funding: This work was supported by `<funder>` [grant number `<XXXX>`];
`<funder>` [grant number `<YYYY>`]; and `<institutional funder>` [grant
number `<ZZZZ>`].

The role of the sponsor(s) in the study was: `<study design / data
collection / data analysis / interpretation / writing the report /
decision to submit / none>`.

> **Action item:** Replace `<funder>`, `<grant number>`, and the role
> placeholder with the real values before submission. Do **not**
> include detailed program or grant-type descriptions; the funder name
> + grant number is sufficient (per Elsevier instruction). When
> funding is from a block grant or general institutional resources,
> name the institution that provided the funds.

## Template 2 — No specific funding

This research did not receive any specific grant from funding agencies
in the public, commercial, or not-for-profit sectors.
